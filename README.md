# Cuba Cart Website

Responsive static website for Cuba Cart.

## Open locally
Double-click `index.html`, or run a local server:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Important edits before publishing
1. Replace the gallery placeholders with actual Cuba Cart photos.
2. Add the business WhatsApp number and change the booking buttons to WhatsApp links.
3. Confirm package descriptions, coverage area, and pricing.
4. Add a custom domain if available.

## Deploy free
- GitHub Pages
- Netlify
- Vercel

All files are plain HTML, CSS and JavaScript, so no build step is required.
